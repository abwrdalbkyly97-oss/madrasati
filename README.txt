مدرستي - نظام مدرسي متكامل (الإصدار 2)

الأدوار:
- مشرف النظام: كل الصلاحيات + إنشاء حساب المدير وموظفي الإدارة + الإعدادات
- الإدارة: الفصول، الطلاب، أولياء الأمور، المعلمون، الجدول، بيانات الدخول، التقارير، الإعلانات
- المدير: ملخص اليوم، الغياب، تقارير الفصول، بحث عن طالب، المعلمون، إعلانات عامة
- المعلم: التحضير، الدرجات، الواجبات، الشروحات، إعلانات لفصوله
- الطالب: الحصص، الواجبات، الدرجات، الحضور، المكتبة
- ولي الأمر: متابعة كل أبنائه + إشعارات الغياب والدرجات

طريقة التحديث مستقبلاً:
ارفع ملف update.zip إلى المجلد الرئيسي في المستودع (Add file > Upload files)
وGitHub يفكه ويبني التطبيق تلقائياً.

ملف firestore.rules: قواعد الأمان، تُنسخ إلى Firebase Console > Firestore > Rules
